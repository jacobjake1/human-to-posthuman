1. **Body** — from biological to substrate-optional
2. **Lifespan** — from mortality to indefinite

4. **Perception** — from shared reality to personalized layers
5. **Emotion** — from hardwired to configurable
6. **Identity** — from singular to fluid
7. **Relationships** — from biological to substrate-spanning
8. **Work/Purpose** — from survival to optional
9. **Reproduction** — from genetic lottery to design
10. **Death** — from universal to optional
11. **Scarcity** — from central to absent
